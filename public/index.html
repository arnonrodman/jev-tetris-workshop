What's happening

Each time a piece spawns, the browser enumerates every legal final placement (rotation × column), describes each one in plain language, and sends them to the server as Choice options. The server calls TypeSafe's jev-latest model with the board as state. Jev returns the chosen placement plus a full probability distribution and a confidence score — shown live on the left.

Built for a TypeSafe AI (Jev) workshop. See README.md for setup and exercises.
