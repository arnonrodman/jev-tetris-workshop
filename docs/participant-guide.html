Participant guide · Jev Tetris Workshop

Your workshop steps

Work through these in order: set up the game, watch Jev play, then change how it decides and measure the result. Tick each step as you finish it. Your ticks and notes are saved in this browser only.

0 of 0 steps
Part A

Set up and run the game

  1. A1

    Check you have what you need

    • Python 3.10 or newer. Check with python3 --version.
    • A TypeSafe API key from console.typesafe.ai/keys. No key yet? You can still do Part A and B, and the game will use the built-in heuristic bot instead of Jev.
    • The jev-tetris-workshop folder on your machine, opened in a terminal or in PyCharm.
  2. A2

    Create a virtual environment and install

    python3 -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt

    In PyCharm: Settings → Python Interpreter → Add Local Interpreter → Virtualenv → New, then run pip install -r requirements.txt in PyCharm's Terminal tab.

  3. A3

    Add your API key

    cp .env.example .env

    Open .env and paste your key after TYPESAFE_API_KEY=. The file must be named exactly .env. It's already in .gitignore, so the key won't be committed.

  4. A4

    Start the server

    python server/app.py

    Wait for Running on http://127.0.0.1:3000. If you see ⚠️ TYPESAFE_API_KEY is not set, go back to A3. In PyCharm, right-click server/app.py → Run 'app'.

    Keep this terminal visible. The server logs every decision here, and it reloads by itself when you save app.py.

  5. A5

    Check the server can see your key

    Open localhost:3000/api/health in your browser, or run:

    curl localhost:3000/api/health
    Done when you see "hasApiKey": true.
  6. A6

    Start a game and find the logs

    1. Open localhost:3000 and press Start.
    2. Open the browser's DevTools console (⌥⌘J on Mac, Ctrl+Shift+J on Windows).

    Each piece logs one line, in the console and in the server terminal:

    [jev] piece T: jev chose p33 (confidence 0.87, 276 ms)
[jev] piece S: HEURISTIC chose p4 — request timed out after 4000 ms
    Done when the badge in "Jev's decision" says jev and you see jev chose lines.
    Seeing only HEURISTIC? The text after the dash tells you why. A 401 means the key is wrong or your access isn't active yet. A timeout usually means a VPN or proxy is blocking api.typesafe.ai.
Part B

Watch how Jev decides

  1. B1

    Watch 20 pieces

    For each piece, look at the "Jev's decision" card: the placement it chose, the confidence bar, the top five probabilities and the latency. Use the speed slider to slow it down.

    Look for boards where confidence drops. Are there several placements that look about equally good?

  2. B2

    Play a few pieces yourself

    Turn off the AI (Jev) control toggle and play. Controls: ← → move, ↓ soft drop, ↑/Z/X rotate, Space hard drop, C hold. Turn the toggle back on when you're done.

Part C

Exercises

Each one builds on the last. The code snippets are starting points; fit them into the existing functions.

  1. C1

    Only trust Jev when it's confident

    When Jev's confidence is below 0.3, use the heuristic's pick instead.

    1. In server/app.py, add a flag to the JSON returned by decide_placement.
    2. In public/index.html, in requestAIDecision, drop Jev's pick when the flag is set, just before the if (chosen) line.
    server/app.py
    "lowConfidence": answer.confidence < 0.3,
    public/index.html
    if (chosen && result.lowConfidence) {
  fallbackReason = `low confidence ${result.confidence}`;
  chosen = null;
}
    Done when some pieces log HEURISTIC chose … — low confidence 0.2….
  2. C2

    Ask a yes/no question about Hold

    Add a Noul question to the same request, and hold the piece when Jev says yes.

    server/app.py
    from typesafe_sdk import Choice, Noul, TypeSafeClient

questions={
    "placement": Choice(...),   # unchanged
    "hold": Noul(instructions=(
        "Would holding the current piece and playing the next one "
        "instead lead to a better outcome?"
    )),
},

# in the returned JSON — .noul is the probability of "yes", 0 to 1
"holdProbability": response.answers["hold"].noul,
    public/index.html · requestAIDecision, after the result arrives
    if (result?.holdProbability > 0.8 && !state.holdUsed) {
  console.log(`[jev] holding ${state.current.type} (p=${result.holdProbability})`);
  holdPiece();   // the next tick asks Jev about the swapped piece
  return;
}
    Tip: the held-piece slot in the UI should start filling up. Make sure the game still runs with no API key, since result is null then.
    Done when you see holding … lines and the piece in the hold box changes during play.
  3. C3

    Ask Jev to score the board

    Add a Score question that rates the board, log it, and compare it with the heuristic.

    Score takes an ordered list of levels. The first item describes score 0, the next score 1, and so on. The answer has .score (a probability-weighted average, so it can fall between levels) and .confidence.

    server/app.py
    from typesafe_sdk import Choice, Noul, Score, TypeSafeClient

# add to questions={...}
"board_health": Score(
    instructions="Rate how healthy this board's surface is",
    criteria=[
        "Very unhealthy: tall stack, many holes, near top-out",
        "Poor: several holes or a very uneven surface",
        "Okay: a few bumps or one hole",
        "Healthy: low, flat, no holes",
    ],
),

# after the call returns
health = response.answers["board_health"]
app.logger.info("[jev] board health %.2f (confidence %.2f)", health.score, health.confidence)
    Note: the board sent with each request is the result of the previous placement, so this rates the board Jev's last move left behind.
    Done when each piece logs a board health line and you can say whether it agrees with how the board looks.
  4. C4

    Change the instructions, not the code

    Change how Jev plays by editing only the instructions text in Choice(...).

    Try one of these, save, and watch a game. The server reloads on save.

    • "Aggressively prioritize clearing multiple lines at once, even if it means a taller stack."
    • "Keep column 9 empty so an I piece can clear four lines at once."
    • "Play as safely as possible: never let any column get above height 6."
    Done when you can point to a visible change in how the stack is built.
  5. C5

    Measure how often Jev agrees with the heuristic

    Play one full game and compute the percentage of pieces where Jev and the heuristic picked the same placement.

    public/index.html · near the top of the script
    const agreement = { same: 0, total: 0 };
    public/index.html · requestAIDecision, inside if (chosen)
    const h = pickHeuristic(placements);
agreement.total++;
if (h.id === chosen.id) agreement.same++;
console.log(`[agree] ${agreement.same}/${agreement.total} = ` +
  `${Math.round(100 * agreement.same / agreement.total)}%`);
    Tip: undo the C1 confidence gate for this run, or the low-confidence pieces won't be counted.
    Done when you have one agreement percentage for a full game.

  • Whether you'd trust Jev for this decision in production, and at what confidence threshold.
